# 内容审核说明（1—3年级）

本目录保存本次人工词语选择和例句，全部属于自编教学补充，不是教材原文。原教材写字表的字、音、顺序、课号和来源保持不变。

候选来自既有四册TXT、同仓教材词表、main-review的词汇review；仅用于提出候选，不作为权威词典。固定pinyin-pro 3.18.2仅作拼音草稿，目标读音逐项对照。旧三上250句经全文校读后，保留适宜项并改正多音误用、低频或不自然表达；以新人工条目覆盖。

第一批：一上100字、三上250字。普通字每项两个真实词语；功能字和受限词素例外明确显示“用法示例”：一上了/又，三上哦ò/螃。哦两项采用带标点的自然话语，不拼伪词；螃的第二项是“螃蟹壳”真实短语，不能假称独立常用词。全部例句与所选其中一项严格关联。

少见读音/构词核验：
- 教育部教育云字典“哦”说明领会、醒悟语气；教材已有ò字音，保留而不覆盖：https://pedia.cloud.edu.tw/Entry/Detail/?search=%E5%93%A6&title=%E5%93%A6
- 教育部《重编国语辞典》“漂亮话”收录piào liang huà；本次只核词形/义项与目标漂piào，例句自行创作，不抄该辞典例句：https://dict.revised.moe.edu.tw/dictView.jsp?ID=25223&la=1&powerMode=0
- 挑tiǎo采用挑灯/挑拨；朝cháo采用朝代/朝向；占zhàn采用占领/占据；差chà采用差不多/差劲；抹mǒ采用涂抹/抹黑，避免抹布mā；保留原教材字音。

例外和覆盖详情见coverage.json。未完成的书不写入半成品。此目录的候选索引含未审核条目，不能直接发布为教学内容。

第二批：一下200字完成，累计550字。另有的/它/她/都/着/还的常见自然搭配明示用法示例，不假称独立常用词。固定库把照片注piān、北斗/烟斗注dòu，人工纠正为piàn、dǒu；教材字音不变。
