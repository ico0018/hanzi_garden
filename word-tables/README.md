# 教材词语表

本目录保存从2026现用人教版教材末尾“词语表”逐课转写的数据。保留课次、词序和跨课重复词，不从写字表组词；原词语表未标拼音，因此 `pinyin` 留空，听写按完整词语朗读。

每册包含版本、出版方、原PDF链接、印刷页码、PDF页码和核对日期。课名优先沿用同册已核对写字表中的课名，词条只取词语表。题目标识由册次、原课次 `lessonKey` 和词语决定，显示课名、词语索引不参与标识。

一年级上下册的目录及末尾均无独立词语表；册次仍可学习生字，但不生成教材词语听写。一年级的目录/末尾核查页码保存在 `source-checks.json`。有独立词语表的册次，由 `book-catalog.js` 的 `wordTableFile` 指向本地JSON。

`source-checks.json` 保存已核对源的课次数、词数和完整课词序摘要，用于检测遗漏、调序和错字。它是维护与测试记录；浏览器运行仅需要册次JSON。

验证命令：`node --test scripts/test-textbook-word-tables.cjs`。
