# 原创学习例句补充

这些 JSON 是按当前生字的两个已有组词逐项编写的学习例句，不是教材原句，
也没有用于补充听写词语表。每册独立保存，重复字可复用同册的同一例句。

`entries` 以汉字为键，每项包含 `groupWord`（当前显示的两个组词之一）
和 `text`（完整自然句）。生成器只填补原先缺句的记录，不替换三上已有句。
三上“噢”原来的关联字段是单字“噢”，与现有两条用法短语不同；经 Manager
确认保留这条自然原句和原关联字段，所有新增例句仍严格使用现有组词。

实际十二册共 2,500 学习记录、5,000 个组词。三上 250 条原句保留，
另外 2,250 条新增；二上原有四条重复生字记录不增删。
此前文档里的 2,600 / 5,200 是汇总加总错误，不代表此次删除生字或组词。

复现：`node scripts/build-twelve-book-curriculum.js`。
检查：`node scripts/test-all-book-sentences.js`，使用应用真实解析器，并逐项对照
固定基线 `84bff5834a1f5eba4f05a8a8f96bb0850d0680cf` 的字音、两组词、
词义、原句及独立词库/UI/进度架构。`--export` 输出分册计数审计。

结构检查不代替自然语言审阅。新增句在编写时逐词检查，再经 QA 按册全量只读
预审并应用具体搭配/用义修订，最终仍须对精确候选独立复验。
