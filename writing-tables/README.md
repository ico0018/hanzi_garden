# 2026 年现用教材写字表

这是经教材原页核对的本地写字表数据，不从远程字库或识字表推算范围。字符、课次和顺序来自人民教育出版社小学语文教材末尾“写字表”。源 PDF 仅作核对证据，不随网站发布。

| 册次 | 字数 |
| --- | ---: |
| 一上 | 100 |
| 一下 | 200 |
| 二上、二下 | 各 250 |
| 三上、三下 | 各 250 |
| 四上、四下 | 各 250 |
| 五上、五下 | 220、180 |
| 六上、六下 | 180、120 |

合计 12 册、2500 个教材位置。各册版本、原书来源、印刷页码和核对时间保存在对应 JSON 的 `source` 字段；`source-checks.json` 另存总字数、课组数和完整字序摘要。四至六年级上册为 2026 秋修订教材，下册标明现用原版，不把尚未核对的后续修订本称作 2026 新版。

## 与原有教材的关系

旧教材中的部分字形、顺序和篇目与现用教材不同，即使总字数相同也不能直接继承位置。因此新表使用 `2026-1-upper` 等独立标识；旧四册 TXT 与 `1-upper`、`2-upper`、`3-upper`、`4-upper` 标识保留。新版掌握记录用稳定课次 `lessonKey` 与汉字定位，补充显示课名时不会使同一字的记录失效。

新表只提供本次核对的写字练习，不编造组词、释义或造句。`readingPhrase` 是帮助多音字听读的提示词，不作为课本词语表或听写题库。

## 拼音与多音字

一年级上下册、二年级上册优先沿用教材写字表的直接拼音标注。其他册次以固定版拼音库的单字注音为初稿，并对课文语境中的多音字显式校正，例如“监生”的监 jiàn、“脉脉”的脉 mò、“雨夹雪”的夹 jiā、“挑促织”的挑 tiǎo。“哼！”作为语气词标为 hng，与哼唱的 hēng 区分。

拼音初稿使用网站原先已采用的 pinyin-pro 3.18.2 在离线整理阶段生成，最终拼音直接存入本地 JSON；教材范围及生字数据的加载均不依赖该库或外网。现有网页仍使用其原有前端依赖来显示旧教材释义拼音。

## 数据维护与验证

每个文件包括 `bookId`、`edition`、`total`、`source` 和有序 `lessons`。每课有唯一 `lessonKey`、显示标题和 `characters`，每字包含 `char`、`pinyin` 及可选 `readingPhrase`。

`writing-tables.js` 会核对册次、字数、课次和字形；缺失数据不会回退成另一册。页面读取失败时会显示重新选择教材的入口。

验证命令：

```text
node --test scripts/test-writing-tables.cjs
node scripts/test-daily-word-bank.js
node scripts/test-cloud-sync.cjs
node scripts/test-parent-ui.cjs
```

更新字表时须重新核对原页并更新来源和字序摘要；不要用“识字表”的会认字替换“写字表”的会写字，也不要把旧词语题库自动分配给新教材标识。
