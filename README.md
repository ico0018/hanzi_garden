# 汉字乐园 Hanzi Garden

一个给小学阶段使用的课内生字学习网页。

它不是刷题系统，也不需要账号。孩子先选择教材，再按课学习生字、听读、看笔顺、自己书写，最后通过每日听写做复习。学习记录保存在当前浏览器里，打开网页就能继续。

## 当前支持

| 教材 | 生字学习 | 每日词语听写 |
| --- | --- | --- |
| 一年级上册 | ✅ | — |
| 一年级下册 | ✅ | — |
| 二年级上册 | ✅ | — |
| 二年级下册 | ✅ | ✅ |
| 三年级上册 | ✅ | ✅ |
| 三年级下册 | ✅（课次待核对） | — |
| 四年级上册 | ✅ | ✅ |
| 四年级下册 | ✅ | 部分词表，待补齐 |
| 五年级上、下册 | ✅ | ✅ |
| 六年级上、下册 | ✅ | ✅ |

当前可用教材以 `book-catalog.js` 中的 `available: true` 为准。

十二册合计 2,500 条生字学习记录（此前 2,600 的汇总为加总错误），每字显示两个组词或明确标注的自然用法短语，并配一条关联例句。新增例句是原创学习内容，不是教材原句；三年级上册已有例句保留。教材课次和版本仍待原书页核验；“听写题库未配置”的册别可选择题量，但不能开始词语听写。

## 主要功能

### 生字学习

- 按课文切换生字
- 显示拼音、组词和词义
- 支持数据中的关联组词与造句
- 点击生字或词语即可朗读
- 真人普通话录音可用时优先播放，加载失败时回退到浏览器中文语音
- 使用 Hanzi Writer 演示笔顺
- 在田字格中按笔顺书写，写错会提示重试
- 书写完成后由孩子自己选择“已学会”或“还要复习”
- 学习状态保存在浏览器 `localStorage`，并按教材分别记录

### 每日听写

三年级上册保留独立的 28 词题库 `每日词语听写题库.txt`；二年级下册和四至六年级两学期另有本地可编辑词语表，见 `curriculum/renjiao/words-*.txt`。这些教材词语表来源为固定版本的社区转录，尚未逐页核对原书；四年级下册来源有缺课，页面明确提示未齐。一年级两册、二年级上册和三年级下册尚无可用独立听写题库。

每天可选择 **10、20 或 30 个词**，默认 10 个；选择会按教材保存在当前浏览器中。当天调小数量会暂时隐藏队列后面的词，调大后恢复原队列并补入到期复习或新词，已标记结果不会丢失。可用词不足时显示实际数量，不重复凑数（目前三年级上册题库共 28 个词）。旧版当天的 15 词队列也会保留，按所选数量显示。流程是：

1. 先听读音
2. 自己写下词语
3. 需要时再查看提示或答案
4. 在田字格中完成每个汉字的书写
5. 最后由孩子自己判断“我会写 / 我不会写”

系统不会自动替孩子判定是否掌握。

“我不会写”的词会更快回来复习；连续标记“我会写”后，复习间隔依次按 2、4、7、15、30、60 天拉开。

## 使用方式

### 错词本

在学习页点击 **错词本**，可以查看词语列表、逐词朗读、全选或只勾选几个词，再点击“听写选中的词”。听写时答案默认隐藏，可重复听读或查看答案。每个汉字都在田字格中完成书写后，孩子才能手动选择“我会写 / 我不会写”，随后进入下一个词；书写工具或汉字笔顺数据加载失败时不能跳过自评门槛，可重新写这个词来重试。完成一轮后，可以单独再练本轮不会写的词。

词表读取仓库根目录的 **`错词.txt`**，各教材共用。文件保存为 UTF-8，一行一个词，只写汉字；空行、`#` 开头的说明行会忽略，重复词按第一次出现的位置合并。不符合格式的行会跳过并在页面提示。初始文件只有说明，未预填孩子的错词。例如可以由家长把实际要练的词加入文件：

```text
# 一行一个词
早晨
穿戴
```

提交文件并更新网站后，在错词本点“刷新词表”读取最新列表；本功能不会从孩子的电脑自动读取本地同名文件。词表为空时显示添加说明，读取失败时提供重新加载按钮。

错词听写结果用词语作为稳定标识，保存在当前浏览器的独立记录中，各教材的错词本共用这些结果；词表重排不丢失已有结果。列表显示最近一次“会写了 / 还要复习”状态，词语不会因标记会写而被自动移除。它与每日听写的队列、复习日期和学习记录分开，不改变每日题量。当前这一轮的选词和进度保留到离开或刷新页面为止；切换功能再回来会保留本轮，正在书写的词从头写。清除站点数据会删除本机结果，不会修改 `错词.txt`。

这个项目没有 Node 构建步骤，也不需要安装依赖。

因为页面会通过 `fetch` 读取本地教材数据，不建议直接双击 `index.html`。在项目目录启动一个静态服务器即可：

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000/welcome.html
```

首页选择教材后，会进入类似：

```text
index.html?book=3-upper
```

的学习页面。

## 部署

项目是纯 HTML / CSS / JavaScript 静态站点，可以直接部署到 Vercel 或其他静态托管服务。

仓库中的 `vercel.json` 会把根路径 `/` 临时重定向到 `/welcome.html`，因此在 Vercel 上不需要额外构建配置。

## 教材数据

教材入口统一配置在：

```text
book-catalog.js
```

每个已开放教材对应一个文本数据文件，例如：

```text
curriculum/renjiao/learning-1-upper.txt
curriculum/renjiao/learning-2-lower.txt
curriculum/renjiao/learning-3-upper.txt
curriculum/renjiao/learning-6-lower.txt
```

原始 `生字数据*.txt` 文件保留不变，其中 `生字数据.txt` 是原三年级上册数据；当前页面使用本地两组词学习覆盖文件。数据来源、补充词审核和已知课次限制见 `curriculum/README.md` 与 `curriculum/renjiao/README.md`。

基础格式如下：

```text
[课文标题]
字|拼音|组词|组词拼音|词义;组词|组词拼音|词义
```

如果需要附加“关联组词 + 造句”，可以在该行末尾追加：

```text
||关联组词|完整句子
```

例如：

```text
晨|chén|早晨|zǎo chén|一天刚开始的时候||早晨|早晨的阳光照进了教室。
```

应用会忽略空行和以 `#` 开头的注释行。

## 项目结构

```text
hanzi_garden/
├── welcome.html              # 教材选择页
├── welcome.js                # 教材选择逻辑
├── index.html                # 主学习页
├── app.js                    # 生字学习、书写、朗读、每日听写
├── styles.css                # 页面样式与响应式布局
├── book-catalog.js           # 教材目录与开放状态
├── daily-word-bank.js        # 每日听写题库解析
├── mistake-notebook.js       # 错词列表、选词复习与独立听写
├── 错词.txt                 # 家长维护的共用错词表，一行一个词
├── 每日词语听写题库.txt       # 三年级上册每日听写词库
├── 生字数据*.txt              # 各册教材数据
├── writing-table-support.js  # 写字表数据适配辅助脚本
├── AUDIO-CREDITS.md          # 音频来源说明
└── vercel.json               # Vercel 根路径跳转
```

## 前端依赖

页面通过 CDN 直接加载：

- [Hanzi Writer](https://hanziwriter.org/)：笔顺动画与书写检测
- [pinyin-pro](https://github.com/zh-lx/pinyin-pro)：中文文本拼音转换

项目本身没有 `package.json`，也没有 npm 安装或打包流程。

## 关于学习记录

所有学习状态都保存在当前浏览器的 `localStorage` 中，没有登录系统，也不会同步到其他设备。

清除浏览器站点数据后，本机学习记录也会一起清除。
