# 汉字乐园 Hanzi Garden

一个给小学阶段使用的课内生字学习网页。

孩子可以先以游客身份选择教材，按课学习生字、听读、看笔顺和书写；二至六年级还可先预习词语，再进行每日听写。游客记录保存在当前浏览器；接入统一账号的站点可以按当前孩子自动同步。

## 当前支持

主书架按 2026 年现用人教版语文教材末尾的“写字表”整理，一至六年级上下册均可选择，共 12 册、2500 个教材位置。每册保留课次及字序，支持听读、看笔顺和书写。四至六年级上册为 2026 秋修订本；下册使用已核对的现用版本，书架会标明版本。

12册生字均已补齐两条词语或明确标记的用法示例，以及一句关联例句，共5000条词例、2500句。补充内容为人工编写的教学材料，不是教材原文；不确定的词音和词义留空。

书架只展示12册现用教材。原有教材数据、旧链接和学习记录保留兼容，不再显示旧教材入口，也不清除记录。主书架使用独立的 `2026-*` 教材标识；新增组词时，新版生字记录仍沿用原写字表的标识。

| 教材 | 生字学习 | 每日词语听写 |
| --- | --- | --- |
| 2026年现用一年级上下册 | ✅ 生字与写字 | 原教材无独立词语表 |
| 2026年现用二至六年级上下册 | ✅ 生字与写字 | ✅ 教材词语表预习与听写 |

当前可用教材以 `book-catalog.js` 中的 `available: true` 为准。

## 主要功能

### 生字学习

- 按课文切换生字
- 2026 写字表显示课次、生字与教材拼音；部分多音字提供听读提示词
- 支持每字2组词及1句关联造句；语气词等受限词素可明确标为“用法示例”，不改教材原字音
- 原有教材显示拼音、组词、词义，以及数据中已配置的关联组词与造句
- 点击生字或词语即可朗读
- 真人普通话录音可用时优先播放，加载失败时回退到浏览器中文语音
- 使用 Hanzi Writer 演示笔顺
- 在田字格中按笔顺书写，写错会提示重试
- 书写完成后由孩子自己选择“已学会”或“还要复习”
- 学习状态保存在浏览器 `localStorage`，并按教材分别记录

### 每日听写

新版（`2026-*`）每日听写读取本地教材词语表，保留原表课次和词序，仅为已核对独立词语表的册次启用。词条不从写字表自动组词，不生成释义或造句。页面分别提示“没有独立词语表”“正在整理”或“加载失败”；词语表加载失败时，生字学习仍可使用。

二至六年级上下册共10册、2168词：二上239 / 二下243、三上250 / 三下271、四上220 / 四下213、五上213 / 五下142、六上215 / 六下162。一年级上下册没有独立词语表，不生成教材词语听写。原表没有拼音，提示中的拼音留空，听写按完整词语朗读。

原有三年级上册（`3-upper`）继续使用 `每日词语听写题库.txt`，保留原题目标识和学习记录。新版题目标识由册次、原表课次标识和词语组成，补充标题、调整目录或插入词语不改变已有题目的标识；同一词在不同课次出现时分别保留。

进入每日听写后先显示今日词表，分为“复习词”和“待学词”。开始前可选10、20或30词；点击词语打开学习窗，听全词读音、观察每个字的本地笔顺并练写。学习窗不计听写成绩，也不会改变听写的书写完成状态。

点“准备好了，开始听写”后，当天数量和词表固定，刷新、换页再返回可继续；已答结果保留，完成后可回词表学习但不重新计分。旧版本今日15词队列若已有结果，会原样保留，次日再选新数量。

听写流程是：

1. 先听读音
2. 自己写下词语
3. 需要时再查看提示或答案
4. 在田字格中完成每个汉字的书写
5. 最后由孩子自己判断“我会写 / 我不会写”

系统不会自动替孩子判定是否掌握。

错词在次日词表以小红三角内白色感叹号标记，并有无障碍文字说明。错词优先于普通到期词，需要连续两个日历日正确才能解除每日强化；同日重复、刷新不累加，跳日重新从一次正确开始，出错清零。解除后保留历史，回到正常间隔；正常词仍按2、4、7、15、30、60天复习。旧unknown记录继续强化；缺少明确错词记录的旧known保留原正常间隔，不仅凭成功次数猜测曾经出错或误加红标。

教材词语表使用 `word-tables/2026-年级-上下册.json`；目录条目的 `wordTableFile` 指向该本地文件。确认教材本身没有独立词语表时，使用 `wordTableStatus: "not-in-textbook"`。未知或尚未整理的册次不填写这两个字段。

词语表数据包含 `schemaVersion: 1`、`bookId`、`edition`、`total`、`source` 和 `lessons`。`source` 记录人民教育出版社、表名“词语表”、原页链接 `url`、印刷页码 `printedPages`、可选PDF页码 `pdfPages` 与核对日期 `reviewedAt`。每课包含稳定的 `lessonKey`、课名 `title` 及按原顺序排列的 `words: [{word, pinyin}]`；未核对拼音时可省略 `pinyin`，不猜填。同课重复词、缺失来源、册次或总数不符均拒绝加载。

运行 `node --test scripts/test-textbook-word-tables.cjs` 检查词序、来源验证、稳定标识、本地加载、队列和复习规则、写完整词后才可自评，以及空表/加载失败提示。

## 使用方式

先安装锁定版本的依赖并生成静态文件；Hanzi Writer、拼音库和笔画数据会一起打包到本站。页面通过 `fetch` 读取数据，不建议直接双击 HTML：

```bash
npm ci
npm run build
python -m http.server 8000 --directory dist
```

然后打开：

```text
http://localhost:8000/welcome.html
```

首页选择教材后，会进入类似：

```text
index.html?book=2026-3-upper
```

的学习页面。

## 部署

部署 `dist/` 的内容。构建明确列出公开页面、运行脚本和教材文件，并包含固定版本的 Hanzi Writer 2.0.2、笔画数据2.0.1、pinyin-pro 3.18.2 及各自许可证。构建按实际教材解析所需汉字，任何必需字缺失、笔画数据损坏或教材格式错误都会失败；不发布 `.git`、`.agents`、环境变量文件或内部脚本。生成的 `dist/`、`vendor/` 和 `node_modules/` 不提交。

`vercel.json` 已指定构建命令和 `dist` 输出目录，并保留根路径到欢迎页的跳转及家长页嵌入限制。腾讯云更新时须保留服务器已定制的 `cloud-config.js`，不要用仓库默认前端配置覆盖，并核对更新前后的文件摘要；其他云脚本和家长页面继续保留。

## 教材数据

教材入口统一配置在：

```text
book-catalog.js
```

新版每册对应 `writing-tables/2026-年级-册次.json`，通过 `writing-tables.js` 读取。JSON 包含课次、字序、拼音和来源页码，维护说明见 [写字表说明](writing-tables/README.md)。部署时必须同时发布这个读取脚本和十二册 JSON。

补充学习内容以 `learningSupportVersion: 1` 标记，每字恰好两个 `words: [{word,pinyin,meaning}]` 和一个 `sentence: {groupWord,text}`；造句须包含其中一个组词。无法核对的词音/释义留空，不改教材生字原拼音。语气词等自然短语使用 `examplesLabel: "用法示例"` 与词项 `kind: "usage"`，可含标点；普通组词仍为纯汉字。无补充标记的旧写字表仍可单独练字。构建同时收集补充组词内需要练写的汉字，缺本地笔画即失败。

本次另有两处经原课语境核对的旧注音纠错：三下第18课“膀”改为bǎng并增加“翅膀”读音提示，第16课“卜”改为bo并增加“萝卜”提示；四下“卜”bǔ保留。检查器只允许这四个精确字段变化，其他原教材字段、全部2500生字记录ID和2168词表ID必须保持一致。运行 `node content-review/check-integrated.cjs` 可复核全量内容与旧记录标识；各批来源和原作者证据见 `content-review/integration-sources.json`。

原有教材继续对应文本数据文件，例如：

```text
生字数据_一年级上册.txt
生字数据_二年级上册.txt
生字数据.txt
生字数据_四年级上册.txt
```

其中 `生字数据.txt` 是原有三年级上册数据。

基础格式如下：

```text
[课文标题]
字|拼音|组词|组词拼音|词义;组词|组词拼音|词义
```

如果需要附加“关联组词 + 造句”，可以在该行末尾追加：

```text
||关联组词|完整句子
```

例如：

```text
晨|chén|早晨|zǎo chén|一天刚开始的时候||早晨|早晨的阳光照进了教室。
```

应用会忽略空行和以 `#` 开头的注释行。

## 前端依赖

页面从本站 `vendor/` 读取固定版本依赖：

- [Hanzi Writer](https://hanziwriter.org/) 2.0.2：笔顺动画与书写检测
- hanzi-writer-data 2.0.1：本站笔画数据
- [pinyin-pro](https://github.com/zh-lx/pinyin-pro) 3.18.2：中文文本拼音转换

`npm ci` 按锁文件安装，`npm run build` 生成部署目录，`npm test` 运行现有回归和笔画资源检查。构建按实际教材、补充组词及旧听写题库收集汉字，全部必须具备有效笔画数据；所需总数记录在生成的笔画清单中。

## 关于学习记录

游客学习状态保存在当前浏览器的 `localStorage` 中。接入统一账号后的登录缓存与云同步规则见下节；新旧教材使用独立记录，旧记录不自动套用到2026写字表。

清除浏览器站点数据后，本机学习记录也会一起清除。
## 统一账号与云同步（开发分支）

保持静态 HTML/JS 与现有免费游客学习。登录 Cookie 只由统一 API 管理，工具不保存认证 Token。部署必须包含 `cloud-config.js`、`cloud-sync.js`、`cloud-ui.js`、`cloud-ui.css`。配置文件中 `apiBase` 默认 `https://api.xuebabangbang.cn`，`portalBase` 默认 `https://xuebabangbang.cn`；腾讯隔离预览可使用相同 origin（或 `apiBase: ''` 同源）。地址末尾不要加 `/`。API 必须允许本站 Origin 和带凭据请求。

每个工具只在自己的 origin 读取游客 localStorage。首次登录不自动搬数据，先选择孩子，再点“导入本机游客记录”确认；原有游客键保留。登录缓存按 `xbb:state:v1:<tool>:<userId>:<profileId>` 隔离，教材/录音等静态资源不进入云数据。页面打开先确认 Session、孩子和云记录，再加载学习流程；Session 暂时不可达时可继续最近孩子的本机缓存，联网后重试验证身份。

学习原数据以 key → 原JSON字符串组成 schemaVersion 1 的 JSON payload；汉字包含生字掌握及每日听写进度、队列，古文包含阅读、学习及屏幕默写进度。旧书籍/课文身份和原有判定规则不变。

本机修改即时持久保存，dirty/generation 随缓存保存，刷新和断网后仍可重试。同步失败显示失败，不显示完成。revision 409 停止自动写入，用户可导出本机+云端冲突+游客的备份并明确选择；选择前不会静默覆盖，选择时另存 `:recovery:<timestamp>` 恢复副本。切孩子重载本工具，原孩子未上传记录仍留在原隔离缓存。账号中心提供完整云端导出。

验证：`node scripts/test-cloud-sync.cjs` 运行11项同步回归；汉字另运行 `node scripts/test-daily-word-bank.js`，古文运行 `node --test tests/*.test.cjs` 与 `python -m unittest discover -s tests`。这两个静态仓库没有 lint/typecheck/build 工程配置，部署是静态文件复制。


## 家长页面与简洁学习页面

`parent.html` 是本工具同origin的家长入口，包含账号中心、孩子切换、同步状态、游客记录导入、备份、冲突选择与恢复。学生页不显示家长入口或记录管理控件，后台仍自动同步，不向孩子展示存储和同步操作。

家长回答一道中文数字计算题、从三个数字中选择正确结果即可进入。账号模式由服务器签发与校验题目，读取统一Session的 `parentReady`；当前登录持续有效，不再输入密码/PIN，也没有15分钟自动锁定。已在账号中心或另一工具进入家长模式后直接继承当前Session。主动“退出家长模式”调用服务端 parent-lock，或退出登录后才失效。游客仅作本机误点确认，以sessionStorage保存当前标签页状态，刷新可继续，主动退出清除；这不替代真正的账号认证。旧游客学习数据和遗留设置不会被删除。

运行 `node scripts/test-parent-ui.cjs`：学生无记录控件、三选一正确/错误答案、已授权Session免重复题目、显式退出、游客刷新保持；原有云同步回归新增服务端Session授权撤销，共11项。家长页题目或请求失败时可换题重试。


统一记录管理在任务小帮手 `/parent/` 中直接显示本工具 `parent.html?embedded=1` 的控件，面板仍在本工具自己的origin读取localStorage。嵌入模式隐藏重复标题、返回学习、切孩子与单独退出，只显示当前孩子和实际导入/备份/同步/冲突按钮；切孩子由中央页面统一重载。嵌入导入和冲突选择使用明确的内嵌确认/取消，点击前不执行数据操作。

`cloud-config.js` 的公开 `parentBase` 默认 `https://taskhelper.xuebabangbang.cn`，隔离预览配置为 `http://localhost:8323`。只接受真实嵌入页面、这个精确origin且source为直接父窗口的type-only游客激活/退出消息；游客授权仅保存在当前widget内存，登录会话仍必须拥有服务器parentReady，绝不通过消息授予登录权限或导入记录。消息不传送学习内容、账号/孩子ID或URL，出站仅ready或整数高度。独立parent.html仍可直接访问。定向家长UI测试现在8项，含错误来源、额外字段、初始化竞态与内嵌确认。
